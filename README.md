# Mindful Blocker

Blocks specified websites with a gentle reminder.

## Description

Mindful Blocker is a Chrome extension designed to help you stay focused by blocking distracting websites. When you attempt to visit a blocked site, you will be redirected to a calming "Blocked" page with a gentle reminder: "Remember, you probably blocked this website for a good reason."

## Installation

1.  Clone or download this repository to your local machine.
2.  Open Google Chrome and navigate to `chrome://extensions/`.
3.  Enable **Developer mode** by toggling the switch in the top right corner.
4.  Click on the **Load unpacked** button.
5.  Select the directory where you saved the extension files (the folder containing `manifest.json`).
6.  The extension should now be installed and visible in your extensions list.

## Usage

1.  Click on the Mindful Blocker icon in the Chrome toolbar. If it's not visible, click the puzzle piece icon and pin it.
2.  Click **"Options"** (or right-click the icon and select "Options") to open the management page.
3.  **To block a site:**
    *   Enter the domain name in the input field (e.g., `example.com`, `facebook.com`).
    *   Click the **"Block Site"** button.
    *   The site will be added to your blocked list immediately.
4.  **To unblock a site:**
    *   Find the site in the list of blocked sites.
    *   Click the **"Unblock"** button next to it.
    *   The site will be removed from the list and accessible again.
